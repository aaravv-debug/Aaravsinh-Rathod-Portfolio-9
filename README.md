## ✨ Features & Highlights

- **Awwwards-Caliber Preloader**: Vintage serif counter with an orbital pencil follower and authentic handwritten Gujarati *"Kem Cho?"* calligraphy SVG draw animation.
- **Monumental Behance Editorial Hero**: Bold typography with cascading letter animations, high-contrast studio portrait cutout, graffiti marker accents, and live "Available for hire" status indicator.
- **Illuminated Academic Pipe Timeline**: Interactive neon blue signal line connecting academic milestones at Gandhinagar University and Super English School.
- **Selected Works Showcase**:
  - **Bright Dental Clinic Web Platform**: Healthcare web app with embedded video demonstration, appointment flow, and direct link to the [Live Vercel Application](https://bright-dental-clinic-omega.vercel.app/).
  - **Cross-Border E-Commerce Platform**: Multi-currency global supply chain UI/UX with interactive prototype.
  - **Digital Brand Identity System**: Modular design templates and prompt architectures.
- **Interactive Modals**: Detailed case study breakdown drawers with architectural problem-solution analysis and tech stack badges.
- **Design System**: Tailored dual-mode palette (Clean Light Mode & Brutalist Dark Mode) with high-contrast accessibility and smooth transitions.
- **Zero-Dependency Architecture**: Built with semantic HTML5, pure Vanilla CSS, and modern JavaScript with GSAP for animations.

## 🚢 Deploying to Vercel

This repository is pre-configured for **instant, zero-error static deployment** on Vercel:

1. Import this repository in [Vercel Dashboard](https://vercel.com/new).
2. Framework Preset: **Other** (Automatic detection).
3. Root Directory: `./` (Default).
4. Click **Deploy**.

---

## 💻 Local Development

Run any static local server or open `index.html` directly in your browser:

```bash
# Using Python:
python -m http.server 4173

# Or using Node.js:
npx serve .
```

Then visit [http://localhost:4173](http://localhost:4173).
